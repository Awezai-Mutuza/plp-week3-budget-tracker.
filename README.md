
# Personal Budget Tracker

## Project Description

The Personal Budget Tracker is a web project designed to help users organize and review their daily expenses. This project builds on my previous HTML and CSS assignments by improving the visual identity, layout, and user experience of the application.

## Visual Design Features

- **Color Palette:** A professional teal, white, and light-green color scheme is used consistently throughout the application.
- **Typography:** Google Fonts are used, with Poppins for headings and DM Sans for body text.
- **Expense Table:** Includes a colored header, borders, cell padding, alternating row colors, and hover effects.
- **Add Expense Form:** Includes styled input fields, a category dropdown, rounded corners, and a matching Add Expense button.
- **CSS Box Model:** Margin, padding, borders, border-radius, and box shadows separate the page into clear sections.
- **Responsive Design:** CSS media queries help the page adapt to smaller screens.
- **Interactive Styling:** Input focus effects and table hover effects improve the user experience.

## Project Files

### index.html

Contains the structure of the webpage, including the page heading, expense form, expense table, image, embedded video, and collapsible help section.

### style.css

Controls the visual appearance of the application, including colors, typography, form styling, table design, spacing, borders, shadows, and responsive layout.

### README.md

Provides information about the project, its features, the technologies used, and the purpose of each project file.

## How to Run the Project

1. Clone or download this GitHub repository.
2. Open the project folder on your computer.
3. Open `index.html` in a web browser.
4. Ensure you have an internet connection for Google Fonts and the embedded YouTube video.

## Current Limitations

The expense records are sample data. The Add Expense button is currently a visual element and does not automatically add expenses. JavaScript functionality will be introduced in a future assignment.

## Learning Outcomes

Through this project, I practiced applying a consistent color palette, using custom fonts, styling HTML tables and forms, and applying the CSS Box Model to create a more polished and user-friendly web interface.
